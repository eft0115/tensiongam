# 텐션감 — 글쓰기 가이드

> 글을 쓸 때마다 이 문서만 열어보시면 됩니다.
> 사이트 구축 사양은 `SPEC.md`, 글 목록과 클러스터는 `CONTENT-PLAN.md`를 보십시오.

## 한눈에 보기

| 항목 | 기준 |
|---|---|
| 제목 | `키워드, 증상 표현` — 키워드가 맨 앞 |
| 요약(첫 h2) | 한 문장. 제목과 다른 표현 |
| 디스크립션 | 2~3줄. 키워드 필수. **가장 중요** |
| 분량 | 3,000~4,000자 |
| 문단 | 3~4줄 |
| 헤딩 | h2 6~8개, h3는 필요시. h1·h4 안 씀 |
| 정렬 | 왼쪽 고정 |
| 문체 | 공손체(~합니다). 단정 금지 |
| 이미지 | 직접 제작물만. 스톡 사진 금지 |

---

## 1. 제목

**형식:** `핵심 키워드, 증상 표현`

키워드를 맨 앞에 둡니다. 독자는 질환명을 모르고 증상으로 검색하므로, 뒤에 증상 표현을 붙여 양쪽을 모두 잡습니다.

| | 예시 |
|---|---|
| 좋음 | `족저근막염, 아침 첫걸음이 유독 아픈 이유` |
| 나쁨 | `족저근막염의 원인과 치료법 총정리` |
| 나쁨 | `아침에 발이 아파요` |

**같은 클러스터 안에서 시작 키워드가 겹치면 안 됩니다.** 어깨 글이 모두 "오십견"으로 시작하면 서로 순위를 갉아먹습니다.

어깨 클러스터 예시:

| 순서 | 시작 키워드 |
|---|---|
| 1편 | 오십견 |
| 2편 | 어깨 통증 시기별 |
| 3편 | 회전근개 파열 |
| 4편 | 방아쇠수지 |
| 5편 | 팔꿈치 통증 |
| 6편 | 손목터널증후군 |

---

## 2. 헤딩 구조

**마크다운은 h2부터 시작합니다.** `#`(h1)은 쓰지 않습니다. 제목은 frontmatter의 `title`에서 자동으로 렌더링됩니다.

```
h1   ← frontmatter title. 마크다운에 쓰지 않음
h2   ← 요약. 한 문장
p    ← 디스크립션 2~3줄
h2   ← 본문 소제목
p
h3   ← 소제목 아래 세부
p
h2   ← 본문 소제목
...
```

### 티스토리 방식과 다릅니다

티스토리는 h1·h2를 플랫폼이 점유하므로 본문 소제목을 h3부터 씁니다. 본 사이트는 h1이 비어 있어 소제목이 h2입니다.

| 티스토리 | 텐션감 |
|---|---|
| h1 제목 (자동) | h1 제목 (컴포넌트) |
| h2 요약 | h2 요약 |
| h3 소제목 | **h2** 소제목 |
| h4 세부 | **h3** 세부 |

**계층은 같고 번호만 한 칸씩 앞입니다.** 목차를 h2 기준으로 뽑기 때문에, 소제목을 h3로 내리면 목차가 비게 됩니다.

---

## 3. 첫 h2 — 요약 한 문장

제목을 다른 표현으로 바꿔 쓰면서, 이 글이 무엇을 다루는지 알립니다.

- h1: `척추관협착증과 허리디스크, 앉을 때와 걸을 때`
- h2: `척추관협착증과 허리디스크, 어떻게 다른지 알아보겠습니다`

제목과 똑같은 문장을 반복하지 않습니다. 키워드 과다로 읽힐 수 있습니다.

---

## 4. 디스크립션 — 본문에서 가장 중요

첫 h2 바로 아래 2~3줄입니다.

- **검색 결과에 노출되는 유일한 본문입니다.** 클릭 여부가 여기서 갈립니다
- 핵심 키워드가 반드시 들어갑니다
- 오늘 무엇을 말하려는지가 명확해야 합니다
- 그대로 frontmatter의 `description`이 됩니다
- 80~120자

**본문을 다 쓴 뒤 마지막에 다시 손보십시오.** 이 부분만큼은 여러 번 고쳐 쓸 가치가 있습니다.

### 예시

> 척추관협착증과 허리디스크는 이름도 낯설고 증상도 비슷해 보입니다. 둘 다 허리가 아프고, 둘 다 다리가 저립니다. 그런데 아파지는 상황이 정반대인 경우가 많습니다. 앉아 있을 때 힘든지, 걸을 때 힘든지에 따라 갈립니다.

---

## 5. 소제목

**독자와 검색엔진 모두 소제목으로 본문 내용을 파악합니다.** 소제목만 훑어도 글의 흐름이 보여야 합니다.

| 나쁨 | 좋음 |
|---|---|
| 두 질환은 무엇이 다른가 | 디스크는 눌리는 문제, 협착증은 좁아지는 문제 |
| 어떻게 해야 하나 | 진료받으러 가실 때 이 네 가지를 메모해 가세요 |
| 주의사항 | 이런 증상이면 글을 읽지 말고 병원으로 가세요 |
| 결론 | 오늘 내용 정리 |

키워드를 자연스럽게 포함시키되, 억지로 넣지 않습니다.

---

## 6. 글 구조 템플릿

| 순서 | 내용 |
|---|---|
| 1 | **요약 h2 + 디스크립션** (키워드 포함) |
| 2 | **이럴 땐 병원으로** — 적색 신호를 앞쪽에 |
| 3 | 왜 그런가 — 비유 중심의 쉬운 설명 |
| 4 | **흔한 오해 하나 바로잡기** |
| 5 | 데이터나 연구 (있을 경우) |
| 6 | 지금 해볼 수 있는 것 / 피해야 할 것 |
| 7 | 진료 때 이렇게 전달하세요 |
| 8 | 오늘 내용 정리 |
| 9 | 참고문헌 + 면책 + 저자 |

**2번을 앞쪽에 두는 이유:** 응급 상황인 사람이 자가 판단 내용을 먼저 읽고 안심해버리면 위험합니다.

**4번은 모든 글에 반드시 들어갑니다.** 다른 글들이 똑같이 말하는 것 중 사실과 다른 하나를 짚어주는 부분이며, 이 사이트의 차별점입니다.

---

## 7. 문체

**공손체(~합니다, ~하십니다)를 씁니다.** 정보체(~다, ~이다)는 쓰지 않습니다.

독자가 40~60대이고, 건강은 조심스럽게 전달해야 하는 주제이기 때문입니다.

| 원칙 | 예시 |
|---|---|
| 지시보다 권유 | "하세요" → "하시는 편이 좋습니다" |
| 단정 금지 | "낫습니다" → "도움이 되는 경우가 많습니다" |
| 용어 풀이 | 유착성 관절낭염(오십견) |
| 문단 길이 | 3~4줄 |

### 금지 표현

- 완치, 근본 치료, 즉시 효과
- "○일 만에", "이것만 하면"
- 특정 병원·제품·시술 추천
- 진단 확정 표현 ("당신은 ○○입니다")

---

## 8. 분량

**3,000~4,000자.**

건강 주제는 깊이가 순위를 만듭니다. 1,500~2,000자로는 표면만 훑게 되며, 그런 글은 이미 포화 상태입니다.

대신 읽기 부담을 줄입니다. 한 문단 3~4줄, h2로 자주 끊기, 표와 목록 적극 활용.

---

## 9. 이미지

| 종류 | 방침 |
|---|---|
| 직접 만든 그래프·표·도해 | 제한 없음 |
| 무료 스톡 사진 | 사용하지 않음 |
| 타인의 이미지 | 절대 금지 |

이미지 최적화가 적용되므로 장수 제한이 필요 없습니다. 다만 의미 없는 장식 사진은 로딩만 늦추고 순위에 도움이 되지 않습니다.

**모든 이미지에 `alt` 속성을 답니다.**
