# 텐션감 — 콘텐츠 계획 (토픽 클러스터 30편)

## 구조 원칙

기둥글(pillar) 1편 + 가지글(cluster) 여러 편이 한 묶음입니다.

- 기둥글은 주제 전체를 넓게 다루고, 모든 가지글로 링크를 보냅니다
- 가지글은 좁고 깊게 다루고, 반드시 기둥글로 되돌아오는 링크를 답니다
- 같은 클러스터 안의 가지글끼리도 서로 링크합니다
- **다른 클러스터로는 함부로 링크하지 않습니다.** 주제 경계가 흐려집니다

이 구조가 있어야 구글이 "이 사이트는 근골격계 전문"이라고 인식합니다.

## 발행 순서

경쟁이 덜한 가지글로 색인과 신뢰를 먼저 쌓고, 기둥글은 가지글이 모인 뒤에 씁니다. 기둥글을 먼저 쓰면 링크 걸 곳이 없습니다.

### 1단계 (1~6편) — 기반
E0 통계 → A1 척추관협착증 → C4 족저근막염 → B4 방아쇠수지 → B1 오십견 → D0 수술 후

**D0을 여기 넣는 이유:** 사이트 정체성을 초반에 확립하기 위해서입니다.

### 2단계 (7~16편) — 확장
각 클러스터 가지글을 고르게. 한 클러스터에 몰지 마십시오.
C1, B2, A3, E1, D1, A2, C2, B5, E2, D2

### 3단계 (17~26편) — 채우기
A4, A5, B3, B6, C3, C5, D3, D4, E3, E4

### 4단계 (27~30편) — 기둥글
A0, B0, C0 + 필요 시 보강

**기둥글은 반드시 마지막에.** 그래야 모든 가지글로 링크를 걸 수 있습니다.

## 내부 링크 규칙

| 상황 | 규칙 |
|---|---|
| 가지글 → 기둥글 | 필수. 글마다 1회 |
| 기둥글 → 가지글 | 필수. 모든 가지글로 |
| 같은 클러스터 가지글끼리 | 자연스러운 곳에 1~2회 |
| 다른 클러스터로 | 꼭 필요할 때만. 남발 금지 |
| 링크 문구 | "여기"가 아니라 대상 글의 주제를 담을 것 |

| 항목 | 기준 |
|---|---|

| 문단 | 3~4줄 |
| H태그 | h1 하나, h2 5~7개 |
| 이미지 | 직접 제작물 위주. 스톡 사진 금지 |
